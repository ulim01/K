Panel Studio 1.0 — 나만의 웹툰 작업실
====================================

실행하기
1. ZIP 파일을 원하는 폴더에 모두 압축 해제하세요.
2. 폴더 안의 'Panel Studio.exe'를 더블클릭하세요.
3. exe 파일뿐 아니라 같은 폴더의 resources, DLL 파일도 함께 보관하세요.
지원 대상: Windows 10/11 64비트(x64). 별도 Node.js 설치나 인터넷 연결이 필요하지 않습니다.
이 배포본은 개인 제작용 서명되지 않은 실행 파일입니다.

첫 화면은 저장소의 배경 이미지를 사용한 편집 가능한 예제입니다.
'새 작업'에서 빈 프로젝트를 시작할 수 있습니다.

캔버스와 페이지
- 각 변 1~8000px, 페이지당 최대 8000×8000px.
- 왼쪽 아래 +로 페이지 추가. 오른쪽 속성에서 크기, 배경, 이름, 순서를 수정합니다.
- 상단 '한 장씩 / 이어 보기'로 페이지를 넘기거나 웹툰처럼 세로로 봅니다.
- 페이지 크기를 변경해도 기존 소재가 자동 확대되지는 않습니다.

말풍선
- 8가지 모양: 타원, 둥근 사각형, 구름, 외침, 생각, 사각형, 속삭임, 내레이션.
- 모서리를 드래그해 크기 조절. Shift를 누르면 비율 유지.
- '꼬리 편집'의 세 점으로 끝점, 몸체에 붙는 위치, 휘어짐을 조절합니다.
- 오른쪽에서 꼬리 폭, 외곽선 굵기/색, 채우기, 대사, 글꼴, 행간, 여백을 수정합니다.
- 내레이션에는 꼬리가 없습니다. 생각 말풍선은 작은 원으로 이어집니다.

효과음과 글꼴
- 12가지 효과음 프리셋의 문구를 원하는 글자로 변경할 수 있습니다.
- 크기, 굵기, 색, 글자 외곽선, 기울기, 자간/행간, 정렬을 조절합니다.
- 기본 한글 글꼴 11종(14개 굵기 파일)을 오프라인으로 제공합니다.
- 글꼴 추가에서 TTF, OTF, WOFF, WOFF2를 불러올 수 있습니다.
- 추가 글꼴은 프로젝트 파일에 포함됩니다. 공유할 때 글꼴 라이선스를 확인하세요.
- 굵기 파일이 없는 글꼴은 브라우저 엔진의 합성 굵기로 표시됩니다.

이미지와 컷
- PNG/JPG/WEBP/GIF/BMP 불러오기 또는 캔버스에 끌어 놓기.
- 사다리꼴/평행사변형/마름모/삼각형/육각형/타원/자유 다각형 자르기.
- '꼭짓점 직접 편집'에서 점 이동, 테두리 더블클릭 또는 + 버튼으로 점 추가.
- '구도 이동'은 잘린 틀 안에서 원본 이미지의 위치를 이동합니다.
- 확대, 불투명도, 투명 그라데이션 강도/방향/시작 위치, 외곽선 굵기/색을 조절합니다.
- 자르기는 비파괴 편집입니다. 원본 이미지 데이터는 프로젝트에 남습니다.
- GIF는 정지 이미지로 처리됩니다. 다각형 자르기는 이미지 원근 변형 기능과는 다릅니다.
- 자유 펜, 컷 테두리, 집중선, 속도선을 별도 레이어로 추가할 수 있습니다.

저장과 내보내기
- '프로젝트 저장' → .panel.json 파일. 페이지/이미지/추가 글꼴을 함께 저장합니다.
- 자동 저장은 현재 PC의 앱 데이터에 최근 프로젝트 한 개만 보관합니다.
  중요한 작업은 프로젝트 파일로 별도 백업하세요.
- '열기'로 저장한 프로젝트의 편집을 이어갑니다.
- PNG/JPG: 현재 페이지 또는 모든 페이지 ZIP. PNG는 투명 배경 지원.
- SVG: 벡터, 원본 이미지, 글꼴 데이터 포함. 다른 프로그램의 글꼴 지원은 다를 수 있습니다.
- 세로 연결 PNG: 최대 32,000px 높이 및 1억 2천만 픽셀. 초과하면 페이지 ZIP을 사용하세요.
- 8000px 캔버스와 여러 고해상도 이미지는 많은 메모리를 사용합니다.

단축키
V 선택 / B 펜 / H 화면 이동 / Space+드래그 화면 이동
Ctrl+휠 확대·축소 / 방향키 1px 이동 / Shift+방향키 10px 이동
Ctrl+Z 실행 취소 / Ctrl+Shift+Z 또는 Ctrl+Y 다시 실행
Ctrl+D 복제 / Ctrl+C 복사 / Ctrl+V 붙여넣기
Ctrl+S 프로젝트 저장 / Ctrl+O 열기 / Ctrl+E 내보내기
Delete 삭제 / Esc 선택 해제 / T 말풍선 꼬리 / C 이미지 모양 편집

데이터와 배포
앱은 계정, 외부 서버, 유료 API를 사용하지 않습니다. 작업 내용은 기기 안에서 처리됩니다.
이 버전에는 PSD/CLIP 호환, CMYK 인쇄, 애니메이션, 실시간 협업 기능이 없습니다.
폰트 라이선스와 Electron/Chromium/JSZip 라이선스는 배포 폴더 및 앱 리소스에 포함됩니다.
Linux의 Chromium에서 편집·저장·출력 기능을 검증하고 Windows x64 실행 파일을 교차 빌드했습니다.
실제 Windows 기기에서 실행한 결과까지 검증한 배포본은 아닙니다.
