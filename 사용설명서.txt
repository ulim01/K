Panel Studio 1.3 — 나만의 웹툰 작업실
====================================

실행하기
1. ZIP 파일을 원하는 폴더에 모두 압축 해제하세요.
2. 폴더 안의 'Panel Studio.exe'를 더블클릭하세요.
3. exe 파일뿐 아니라 같은 폴더의 resources, DLL 파일도 함께 보관하세요.
지원 대상: Windows 10/11 64비트(x64). 별도 Node.js 설치나 인터넷 연결이 필요하지 않습니다.
이 배포본은 개인 제작용 서명되지 않은 실행 파일입니다.

처음 실행하면 빈 캔버스로 시작합니다. 기본 배경 라이브러리는 제거했습니다.
이전에 작업한 프로젝트는 자동으로 복원되며, '새 작업'에서 빈 프로젝트를 시작합니다.

캔버스와 페이지
- 각 변 1~8000px, 페이지당 최대 8000×8000px.
- 상단 ‘캔버스 크기’에서 언제든 가로·세로와 프리셋을 변경합니다. 소재를 선택한 상태에서도 사용할 수 있습니다.
- 왼쪽 아래 +로 페이지 추가. 오른쪽 속성에서 배경, 이름, 순서를 수정합니다.
- 상단 '한 장씩 / 이어 보기'로 페이지를 넘기거나 웹툰처럼 세로로 봅니다.
- 페이지 크기를 변경해도 기존 소재가 자동 확대되지는 않습니다.

말풍선
- 기본 8종: 타원, 둥근 사각형, 구름, 외침, 생각, 사각형, 속삭임, 내레이션.
- ‘모음 1’ 11종과 ‘모음 2’ 33종으로 참고 이미지의 말풍선 44종을 추가했습니다. 기본과 합쳐 52종입니다.
- 모음 1은 첫 이미지의 왼쪽 위부터 행 순서, 모음 2는 두 번째 이미지의 01~33 번호로 찾습니다.
- 새로운 말풍선도 크기·테두리·대사·꼬리를 편집하고 내 소재에 저장할 수 있습니다.
- 이어진 타원(1-03), 이어진 사각형(2-17), 녹아내리는 말풍선(2-33)은 오른쪽 ‘첫 번째 대사 / 두 번째 대사’에 각각 입력합니다.
- 구름 생각 말풍선(2-32)은 구름 몸체와 원형 꼬리입니다. 기본 생각 말풍선의 몸체는 타원입니다.
- 모서리를 드래그해 크기 조절. Shift를 누르면 비율 유지.
- '꼬리 편집'의 세 점으로 끝점, 몸체에 붙는 위치, 휘어짐을 조절합니다.
- 오른쪽에서 꼬리 폭, 외곽선 굵기/색, 채우기, 대사, 글꼴, 행간, 여백을 수정합니다.
- 내레이션은 각진 사각형이며 꼬리가 없습니다. 생각 말풍선은 타원형 몸체와 작은 원으로 이어지는 꼬리입니다.
- 구름 말풍선은 둥글고 넓은 굴곡으로 표시됩니다.
- 상단 ‘텍스트만 추가’로 말풍선 없는 글자를 넣을 수 있습니다.
- 텍스트 속성의 ‘왼쪽 / 중앙 / 오른쪽’ 버튼으로 정렬합니다. 말풍선과 효과음에도 적용됩니다.

효과음과 글꼴
- 12가지 효과음 프리셋의 문구를 원하는 글자로 변경할 수 있습니다.
- 크기, 굵기, 색, 글자 외곽선, 기울기, 자간/행간, 정렬을 조절합니다.
- 기본 한글 글꼴 11종(14개 굵기 파일)을 오프라인으로 제공합니다.
- 글꼴 추가에서 TTF, OTF, WOFF, WOFF2를 불러올 수 있습니다.
- 추가 글꼴은 프로젝트 파일에 포함됩니다. 공유할 때 글꼴 라이선스를 확인하세요.
- 굵기 파일이 없는 글꼴은 브라우저 엔진의 합성 굵기로 표시됩니다.

내 말풍선·효과음
- 말풍선/효과음 탭의 ‘내 말풍선 만들기’ 또는 ‘내 효과음 만들기’로 새 소재를 만듭니다.
- 캔버스에서 모양·크기·꼬리·문자·스타일을 다듬은 후 ‘선택한 소재 저장’을 누릅니다.
- 오른쪽 속성의 ‘내 말풍선으로/내 효과음으로 저장’ 버튼도 사용할 수 있습니다.
- ‘내 그림 불러오기’로 직접 그린 PNG/JPG/WEBP/GIF/BMP를 소재로 추가합니다. 투명 PNG를 권장합니다.
- 그림 소재는 이미지로 편집됩니다. 대사가 필요하면 ‘텍스트만 추가’로 위에 올리세요.
- 왼쪽 ‘내 말풍선/내 효과음’에서 소재를 누르면 캔버스에 추가됩니다.
- 내 소재는 최대 200개까지 저장되며 앱을 다시 실행하거나 새 프로젝트를 만들어도 유지됩니다.
- 소재 카드의 ×는 내 소재에서만 삭제합니다. 캔버스에 이미 놓인 소재는 유지됩니다.
- ‘내 소재 내보내기’는 그림·추가 글꼴을 포함한 .panel-library.json 백업을 만듭니다.
- 다른 PC에서 ‘소재 파일 불러오기’로 복원합니다. 이미 있는 같은 소재는 중복 추가하지 않습니다.
- 내 소재 목록은 프로젝트 파일과 별도로 보관됩니다. PC 이동·백업 시 두 파일을 함께 저장하세요.

컷 안에 이미지 넣기
- 왼쪽 컷·효과에서 원하는 컷 모양을 추가합니다.
- 컷 위에 이미지 파일을 끌어 놓거나, 컷을 선택하고 ‘컷에 이미지 넣기’를 누릅니다.
- ‘프로젝트 이미지에서 선택’으로 이미 사용하는 이미지를 복사해 넣을 수도 있습니다.
- 컷 한 개에 이미지 한 장을 넣으며, 이미지 교체·빼기와 실행 취소를 지원합니다.
- 컷을 더블클릭하거나 ‘안쪽 이미지 편집’을 누르면 이미지 편집 모드입니다.
- 컷 안을 드래그해 이미지 위치를 이동하고, 초록 모서리로 비율을 유지하며 크기를 조절합니다.
- 오른쪽의 이미지 크기(0.1–20배), 이미지 X/Y(px)로도 정밀하게 조절합니다.
- 이미지 편집 중 방향키는 안쪽 이미지만 이동합니다. Shift+방향키는 10px입니다.
- ‘컷 편집으로’ 또는 Esc를 누르면 컷 자체의 위치·크기를 다시 조절합니다.
- 컷 테두리에서 두께(0–100px)와 색을 조절합니다. 0px로 하면 테두리가 사라집니다.
- 잘린 바깥 부분은 보이지 않으며 원본 이미지는 프로젝트에 보관됩니다.
- 모양 편집으로 컷 꼭짓점을 바꾸어도 안쪽 이미지와 테두리가 함께 따라갑니다.

정렬 안내선과 스냅
- 상단 ‘스냅 안내선’은 기본으로 켜져 있습니다. 버튼으로 켜거나 끕니다.
- 컷·말풍선·이미지를 드래그하면 캔버스 중앙·가장자리와 다른 소재의 중심·가장자리에 맞춰집니다.
- 정렬되는 위치에 분홍색 안내선이 표시되고, 손을 놓으면 사라집니다.
- 회전하지 않은 소재는 모서리로 크기를 바꿀 때도 가장자리가 맞춰집니다.
- 이미지·컷 등의 위쪽 동그란 회전 핸들을 움직이면 각도와 회전 안내선이 표시됩니다.
- 0°, 15°, 30°, 45°, 90° 등 15° 간격의 각도에서 3° 이내로 가까워지면 맞춰집니다.
- 같은 페이지의 다른 소재와 평행하거나 직각인 각도에도 맞춰지고, 기준 소재의 방향을 표시합니다.
- Shift+회전은 15° 단위로 고정하고, Alt+회전은 자동 맞춤을 잠시 해제합니다.
- 오른쪽 ‘회전’ 숫자에는 원하는 정확한 각도를 직접 입력할 수 있습니다.
- Alt를 누른 채 드래그하면 스냅을 잠시 해제합니다. Shift+크기 조절은 비율을 유지합니다.
- 숨긴 소재와 다른 페이지의 소재에는 맞추지 않습니다. 잠긴 소재에는 정렬할 수 있습니다.
- 안내선과 이미지 편집용 핸들은 내보낸 이미지에 포함되지 않습니다.

이미지와 컷
- PNG/JPG/WEBP/GIF/BMP 불러오기 또는 캔버스에 끌어 놓기.
- 사다리꼴/평행사변형/마름모/삼각형/육각형/타원/자유 다각형 자르기.
- '꼭짓점 직접 편집'에서 점 이동, 테두리 더블클릭 또는 + 버튼으로 점 추가.
- '안쪽 이미지 편집'은 잘린 틀 안에서 원본 이미지의 위치와 크기를 변경합니다.
- 확대, 불투명도, 투명 그라데이션 강도/방향/시작 위치, 외곽선 굵기/색을 조절합니다.
- 자르기는 비파괴 편집입니다. 원본 이미지 데이터는 프로젝트에 남습니다.
- GIF는 정지 이미지로 처리됩니다. 다각형 자르기는 이미지 원근 변형 기능과는 다릅니다.
- 자유 펜, 컷 테두리, 집중선, 속도선을 별도 레이어로 추가할 수 있습니다.

저장과 내보내기
- '프로젝트 저장' → .panel.json 파일. 페이지/이미지/추가 글꼴을 함께 저장합니다.
- 자동 저장은 현재 PC의 앱 데이터에 최근 프로젝트 한 개만 보관합니다.
  중요한 작업은 프로젝트 파일로 별도 백업하세요.
- '열기'로 저장한 프로젝트의 편집을 이어갑니다. 기존 1.0/1.1/1.2 프로젝트도 그대로 열 수 있습니다.
- PNG/JPG: 현재 페이지 또는 모든 페이지 ZIP. PNG는 투명 배경 지원.
- SVG: 벡터, 원본 이미지, 글꼴 데이터 포함. 다른 프로그램의 글꼴 지원은 다를 수 있습니다.
- 세로 연결 PNG: 최대 32,000px 높이 및 1억 2천만 픽셀. 초과하면 페이지 ZIP을 사용하세요.
- 8000px 캔버스와 여러 고해상도 이미지는 많은 메모리를 사용합니다.

단축키
V 선택 / B 펜 / H 화면 이동 / Space+드래그 화면 이동
Ctrl+휠 확대·축소 / 방향키 1px 이동 / Shift+방향키 10px 이동
Ctrl+Z 실행 취소 / Ctrl+Shift+Z 또는 Ctrl+Y 다시 실행
Ctrl+D 복제 / Ctrl+C 복사 / Ctrl+V 붙여넣기
Ctrl+S 프로젝트 저장 / Ctrl+O 열기 / Ctrl+E 내보내기
Delete 삭제 / Esc 선택 해제 / T 말풍선 꼬리 / C 이미지 모양 편집

데이터와 배포
앱은 계정, 외부 서버, 유료 API를 사용하지 않습니다. 작업 내용은 기기 안에서 처리됩니다.
이 버전에는 PSD/CLIP 호환, CMYK 인쇄, 애니메이션, 실시간 협업 기능이 없습니다.
폰트 라이선스와 Electron/Chromium/JSZip 라이선스는 배포 폴더 및 앱 리소스에 포함됩니다.
Linux의 Chromium에서 편집·저장·출력 기능을 검증하고 Windows x64 실행 파일을 교차 빌드했습니다.
실제 Windows 기기에서 실행한 결과까지 검증한 배포본은 아닙니다.
