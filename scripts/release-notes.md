# Panel Studio 1.2.0

컷 안 이미지 편집과 정렬 스냅 안내선을 추가한 Windows 웹툰 작업실입니다.

## 다운로드 및 실행

`Panel-Studio-1.2.0-Windows-x64.zip`을 다운로드해 **전체 압축을 해제**한 다음 `Panel Studio.exe`를 실행하세요. Windows 10/11 x64용이며 별도 Node.js 설치나 인터넷 연결이 필요하지 않습니다.

## 이번 버전

- **컷 안에 이미지 넣기**: 이미지 파일을 컷 위에 끌어 놓거나, 컷 선택 후 파일 또는 프로젝트 이미지를 선택합니다. 사다리꼴·평행사변형·타원·자유 다각형 컷의 경계에 맞춰 잘립니다.
- **안쪽 이미지만 이동·확대**: 컷을 더블클릭하고 이미지 안쪽을 드래그하거나 초록 모서리로 크기를 조절합니다. 이미지 크기·X/Y 입력과 방향키도 사용할 수 있습니다. Esc 또는 ‘컷 편집으로’를 누르면 컷 자체를 편집합니다.
- **컷 테두리 두께·색 조절**: 오른쪽 ‘컷 테두리’에서 0–100px로 조절합니다.
- **스냅 안내선**: 캔버스 중앙·가장자리, 다른 소재의 중심·가장자리에 가까워지면 분홍색 안내선과 자동 맞춤이 동작합니다. 회전하지 않은 소재의 크기 조절도 지원합니다. 상단에서 켜고 끄거나 Alt로 잠시 해제할 수 있습니다.
- **기본 배경 라이브러리 제거**: 배경 번들을 제외했고 처음 실행할 때 빈 캔버스로 시작합니다.

기존 1.0/1.1 프로젝트와 내 소재를 이어서 사용할 수 있습니다. 기존 프로젝트에 저장한 이미지도 보존됩니다. 컷 한 개에는 이미지 한 장을 넣으며 이미지 교체·빼기·실행 취소를 지원합니다. 안내선과 편집 핸들은 출력 파일에 포함되지 않습니다.

이전 버전의 각진 내레이션, 타원형 생각 말풍선·원형 꼬리, 텍스트만 추가, 사용자 말풍선·효과음, 글꼴, 다각형 이미지 편집, 최대 8000×8000px 캔버스와 PNG/JPG/SVG·ZIP 내보내기도 포함합니다.

실제 Chromium에서 편집·저장·복원·출력 및 스냅 동작을, Linux Electron에서 패키지 시작·파일 저장과 이전 버전 작업 복원을 검증했습니다. 실제 Windows PC 실행 검증 및 코드 서명은 포함하지 않습니다. 자세한 사용법은 ZIP 안의 `먼저 읽어주세요.txt`에 있습니다.
