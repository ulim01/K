# Panel Studio 1.0.0

한국어 UI의 오프라인 Windows 웹툰 편집기입니다.

## 다운로드 및 실행

`Panel-Studio-1.0.0-Windows-x64.zip`을 다운로드하고 전체 압축을 해제한 다음 `Panel Studio.exe`를 실행하세요. Windows 10/11 x64용이며 별도의 Node.js 설치는 필요하지 않습니다.

## 기능

- 최대 8000×8000px 캔버스, 여러 페이지 및 세로 이어 보기
- 말풍선 8종과 꼬리 끝점·붙는 위치·곡선 편집
- 효과음 12종, 한글 글꼴 11종 및 사용자 글꼴 추가
- 이미지 다각형 자르기, 투명도, 방향별 그라데이션, 외곽선
- 레이어, 자유 펜, 실행 취소, 자동 저장, 프로젝트 저장
- PNG/JPG/SVG, 전체 페이지 ZIP 및 세로 연결 PNG 내보내기

편집·저장·내보내기 테스트와 Linux Electron에서의 패키지 시작·파일 저장을 검증했습니다. 실제 Windows PC 실행 검증 및 코드 서명은 포함하지 않습니다. 사용 설명서는 ZIP 안의 `먼저 읽어주세요.txt`에 있습니다.
