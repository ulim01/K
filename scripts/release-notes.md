# Panel Studio 1.1.0

한국어 UI의 오프라인 Windows 웹툰 편집기입니다.

## 다운로드 및 실행

`Panel-Studio-1.1.0-Windows-x64.zip`을 다운로드하고 전체 압축을 해제한 다음 `Panel Studio.exe`를 실행하세요. Windows 10/11 x64용이며 별도의 Node.js 설치는 필요하지 않습니다.

## 이번 버전

- 내레이션을 각진 사각형으로 변경했습니다.
- 상단 **텍스트만 추가** 버튼으로 말풍선 없이 글자를 넣을 수 있습니다.
- 생각 말풍선을 타원형 몸체와 조절 가능한 원형 꼬리로 변경했습니다.
- 구름 말풍선을 부드럽고 넓은 굴곡으로 다듬었습니다.
- **내 말풍선 / 내 효과음 만들기**, 선택한 소재 저장, 직접 그린 이미지 추가를 지원합니다.
- 내 소재는 재실행과 새 프로젝트에서도 유지됩니다. 그림·추가 글꼴과 함께 파일로 백업하고 불러올 수 있습니다.
- 상단에 **캔버스 크기**와 현재 가로·세로를 항상 표시합니다. 소재를 선택한 상태에서도 크기를 변경할 수 있습니다.

기존 1.0 프로젝트를 그대로 열 수 있습니다. 말풍선·효과음의 글자와 스타일은 계속 편집할 수 있으며, 가져온 그림 소재는 이미지로 편집합니다. 내 소재 목록은 프로젝트와 별도로 보관하므로 다른 PC로 옮길 때는 **내 소재 내보내기**도 사용하세요.

최대 8000×8000px 캔버스, 여러 페이지·세로 보기, 이미지 다각형 자르기·투명도·그라데이션·외곽선, 한글 글꼴과 사용자 글꼴, 레이어·실행 취소·자동 저장, PNG/JPG/SVG·ZIP 내보내기를 제공합니다.

편집·저장·복원·출력 테스트와 Linux Electron에서의 패키지 시작·파일 저장을 검증했습니다. 실제 Windows PC 실행 검증 및 코드 서명은 포함하지 않습니다. 사용 설명서는 ZIP 안의 `먼저 읽어주세요.txt`에 있습니다.
