# Panel Studio 1.3.0

회전 스냅 안내선, 텍스트 정렬 버튼, 참고 이미지의 말풍선 44종을 추가한 Windows 웹툰 작업실입니다.

## 다운로드 및 실행

`Panel-Studio-1.3.0-Windows-x64.zip`을 다운로드해 **전체 압축을 해제**한 다음 `Panel Studio.exe`를 실행하세요. Windows 10/11 x64용이며 별도 Node.js 설치나 인터넷 연결이 필요하지 않습니다.

## 이번 버전

- **회전 스냅 안내선**: 이미지·컷 등의 회전 핸들을 움직이면 현재 각도와 안내선이 표시됩니다. 15° 간격의 기본 각도, 다른 소재와 평행하거나 직각인 각도에 맞춰집니다. Alt로 자동 맞춤을 잠시 해제하고 Shift로 15° 단위 회전을 고정합니다.
- **텍스트 정렬 버튼**: 오른쪽 텍스트 속성에서 왼쪽·중앙·오른쪽 정렬을 바로 선택합니다. 텍스트·효과음·말풍선과 PNG/SVG 출력에 적용됩니다.
- **말풍선 44종 추가**: 두 참고 이미지의 타원·사각형·사다리꼴·손그림·외침·구름·이어진 말풍선을 편집 가능한 벡터로 구현했습니다. 말풍선 탭의 ‘모음 1’ 11종, ‘모음 2’ 33종에서 번호로 찾습니다. 기존 8종을 포함해 총 52종입니다.
- **이어진 말풍선의 두 대사**: 1-03, 2-17, 2-33은 각 칸의 대사를 따로 입력합니다. 2-32의 구름 생각 말풍선에는 원형 꼬리가 있습니다. 새 말풍선의 크기·테두리·꼬리·문자를 조절하고 내 소재로 저장할 수 있습니다.

기존 1.0–1.2 프로젝트와 내 소재를 이어서 사용할 수 있습니다. 컷 안 이미지 이동·크기 조절, 컷 테두리 두께, 위치 스냅 안내선, 사용자 말풍선·효과음, 폰트 추가, 최대 8000×8000px 캔버스와 PNG/JPG/SVG·ZIP 내보내기도 포함합니다. 기본 배경 라이브러리는 제거된 상태로 유지됩니다.

실제 Chromium에서 회전 드래그·정렬 출력 픽셀·44종 말풍선 추가·두 대사 저장·PNG/SVG 출력과 기존 편집 기능을 검증했습니다. Linux Electron에서 패키지 시작·파일 저장 및 1.2 작업 복원을 확인했습니다. 실제 Windows PC 실행 검증 및 코드 서명은 포함하지 않습니다. 자세한 사용법은 ZIP 안의 `먼저 읽어주세요.txt`에 있습니다.
